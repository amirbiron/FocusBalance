# FocusBalance 🎯
## אפיון מוצר - ממשק ווב לניהול והפחתה של מינון ריטלין

> דשבורד ידידותי וצבעוני המיועד למפתחים ועובדי ידע המעוניינים להפחית באופן מודע וזהיר את צריכת הריטלין שלהם, תוך שמירה על פרודוקטיביות.

---

## 1. רקע ומטרות

### הבעיה
מפתחים ועובדי ידע רבים שמשתמשים בריטלין (Methylphenidate) חווים זחילת מינון - לקיחת מנה נוספת מעבר למרשם בגלל לחץ של דדליין, סשן קוד ארוך, או הרגל. הדפוס הזה גורם לסבילות, פגיעה בשינה, חרדה, ובסופו של דבר ירידה בפרודוקטיביות.

### מטרת המוצר
לספק כלי מעקב חכם המאפשר למשתמש:
- להבין את דפוסי הצריכה שלו
- לזהות טריגרים שגורמים לנטילה נוספת
- להפחית מינון בצורה הדרגתית ובת-קיימא
- לשמור על פרודוקטיביות תוך הפחתת התלות

### עקרון מנחה
**זה לא כלי רפואי** - זה כלי מעקב אישי. כל החלטה על שינוי מינון חייבת להיעשות בהתייעצות עם הרופא המטפל. הממשק מציג זאת בבירור.

### קהל יעד ראשוני
מפתחי תוכנה, אנשי מחקר, סטודנטים לתארים מתקדמים - אנשים עם ADHD מאובחן, מינון מרשם קבוע, ומודעות לבעיית הצריכה העודפת.

## 2. עקרונות עיצוב

| עיקרון | משמעות |
|--------|--------|
| **חמלה לפני שיפוט** | אין הודעות "נכשלת" או אדום מאיים. מינון עודף = "הבנו, בוא ננתח" |
| **מינימום חיכוך** | תיעוד מנה ב-2 קליקים מקסימום. אם זה לוקח יותר - המשתמש יפסיק |
| **תובנות, לא נתונים גולמיים** | גרפים מספרים סיפור, לא עומס נתונים |

| **שפה ידידותית** | "מנה" ולא "מינון", "טריגר" ולא "סיבת נטילה לא מתוכננת" |

## 4. פירוט מסכים

### 4.1 🏠 דשבורד ראשי

**מטרה:** סקירה מהירה של "איפה אני היום" ב-10 שניות.

**רכיבים (מלמעלה למטה):**

1. **כרטיס "היום שלך"**
   - מנות שנלקחו היום (X מתוך Y מתוכננות)
   - שעה של מנה אחרונה + "צבע" מצב (ירוק/צהוב/כתום - בלי אדום)
   - מד התקדמות יומי ויזואלי

2. **כפתור פעולה ראשי - "תיעוד מנה" (FAB גדול)**
   - תמיד נגיש, בולט אבל לא לוחץ
   - לחיצה פותחת את ה-Quick Log

3. **רצף ימים (Streak)**
   - "5 ימים ברצף ביעד 🌱"
   - גישת gamification עדינה - בלי לחץ, רק חיזוק חיובי

4. **גרף שבועי קטן**
   - בר-צ'ארט של מנות יומיות ב-7 ימים אחרונים
   - קו אופקי = יעד יומי
   - לחיצה מובילה לתובנות

5. **תובנת היום**
   - משפט אחד מבוסס נתונים: "שמתי לב שאתה לוקח מנה שנייה בעיקר בימי שני - יום עם פגישות?"
   - מתחלף יומית

6. **תזכורת עדינה**
   - "המנה הבאה: 14:00" (אם רלוונטי)

---

### 4.2 ➕ תיעוד מהיר (Quick Log)

**מטרה:** לאפשר תיעוד מנה ב-2-3 קליקים בלי קוגניטיב לואד.

**שלבים (modal/sheet):**

**שלב 1 - "לקחת עכשיו או קודם?"**
- כפתור גדול: "עכשיו" (ברירת מחדל)
- כפתור משני: "בחר שעה" → time picker

**שלב 2 - "כמה?"**
- צ'יפים של מינונים נפוצים: 10mg | 20mg | אחר
- מבוסס על המינונים שהמשתמש הגדיר בהגדרות

**שלב 3 - "מה הוביל לזה?" (אופציונלי - אפשר לדלג)**

זה הלב של המוצר. צ'יפים לחיצים:

| קטגוריה | טריגרים |
|---------|---------|
| 🎯 משימה | דדליין, באג מסובך, code review, ישיבה |
| 🧠 קוגניטיבי | קושי בריכוז, ערפול, רוצה flow |
| 😴 פיזי | עייפות, חוסר שינה, אחרי ארוחה |
| 😰 רגשי | חרדה, שעמום, דחיינות |
| 🔄 הרגל | "פשוט הזמן" |
| ✨ אחר | טקסט חופשי |

**שלב 4 - אישור**
- "תועד ✓" עם משוב חיובי קצר
- אם זו מנה מעבר ליעד היומי: "תועד. ננתח את זה ביחד מחר 💜" (בלי שיפוט)

---

### 4.3 📊 תובנות וסטטיסטיקות

**מטרה:** להפוך נתונים לסיפור.

**טאבים:**

**טאב "טריגרים"**
- ענן תגיות / בר-צ'ארט של הטריגרים השכיחים
- "ב-30 הימים האחרונים, 'דדליין' היה הטריגר ל-40% מהמנות הנוספות"
- המלצה לכל טריגר עיקרי (למשל: "דדליין → נסה לחלק את המשימה לבלוקים של 25 דק'")

**טאב "דפוסי זמן"**
- מפת חום שעה-יום של נטילות
- "המנות הנוספות שלך מתרכזות בין 15:00-17:00 בימי ב'-ה'"

**טאב "מגמה"**
- גרף קווי של ממוצע יומי לאורך שבועות/חודשים
- השוואה ליעד
- אבני דרך מסומנות ("עברת לתוכנית הפחתה")

**טאב "מתאמים"**
- אם המשתמש מתעד גם שינה/מצב רוח: מתאמים בסיסיים
- "בימים שישנת פחות מ-6 שעות, לקחת בממוצע 1.3 מנות יותר"

---

### 4.4 🎯 תוכנית הפחתה

**מטרה:** להגדיר יעד ריאלי ולעקוב אחריו.

**רכיבים:**

1. **הגדרת יעד**
   - "מאיפה אני מתחיל": ממוצע נוכחי (חישוב אוטומטי מ-14 ימים אחרונים)
   - "לאן אני רוצה להגיע": יעד מינון יומי
   - "בכמה זמן": בחירת קצב (איטי/מתון/מהיר) - עם המלצה והסבר

2. **לוח זמנים ויזואלי**
   - גרף שמראה את הירידה ההדרגתית המתוכננת לאורך השבועות
   - אבני דרך שבועיות

3. **התאמה אדפטיבית**
   - אם המשתמש מפספס יעד שבועי 2 שבועות ברצף - הצעה להאט את הקצב
   - "אין בושה להאט - הפחתה איטית = הפחתה מצליחה"

4. **תזכורת לרופא**
   - "עברו 3 חודשים מאז הביקור האחרון - לתאם פגישה?"
   - כפתור ליצוא דוח PDF מתאים להראות לרופא

---

### 4.5 📅 יומן והיסטוריה

**מטרה:** תצוגת לוח שנה של כל הנטילות, לעריכה ובחינה.

- תצוגת חודש עם נקודות צבעוניות לכל יום (ירוק=ביעד, צהוב=מעט מעל, כתום=הרבה מעל)
- לחיצה על יום → פירוט מנות וטריגרים של היום
- אפשרות לערוך/למחוק רשומות בדיעבד
- חיפוש וסינון

---

### 4.6 ⚙️ הגדרות ופרופיל

**קטגוריות:**

- **פרופיל רפואי** (מקומי בלבד!)
  - מינון מרשם יומי
  - מינוני יחידה (לכפתורים המהירים)
  - שעות נטילה מתוכננות
  - שם הרופא המטפל (אופציונלי)

- **התראות**
  - תזכורות לנטילה מתוכננת
  - סיכום שבועי
  - השבתת התראות לפי שעות (Do Not Disturb)

- **פרטיות ונתונים**
  - יצוא נתונים (JSON / CSV / PDF לרופא)
  - מחיקת כל הנתונים
  - גיבוי מקומי

- **טריגרים מותאמים**
  - הוספה/עריכה של רשימת הטריגרים

## 6. שפה ויזואלית

## 7. סטאק טכני מוצע

| שכבה | טכנולוגיה | למה |
|------|----------|------|
| Frontend | React + TypeScript + Vite | אקוסיסטם בוגר, טיפוסים |
| UI | Tailwind + shadcn/ui | מהיר, נגיש, מתועד |
| State | Zustand / React Query | פשוט יותר מ-Redux |
| גרפים | Recharts / Visx | RTL וגמיש |
| DB מקומית | IndexedDB (Dexie.js) | פרטיות, אופליין |
| Backend (אם נדרש) | Node + Postgres | סטנדרט, פשוט להוסיף סנכרון בעתיד |
| Auth (אם נדרש) | Clerk / Supabase Auth | פתרון מהיר |
| Deployment | Vercel / Netlify | DX מעולה |

**הערה:** ב-MVP אפשר לוותר על Backend לגמרי - הכל מקומי בדפדפן. סנכרון בין מכשירים = פיצ'ר עתידי.

## 8. דרישות לא-פונקציונליות

- **פרטיות:** ברירת מחדל = הכל מקומי. אם יש חשבון, הצפנה ב-rest.
- **נגישות:** WCAG 2.1 AA. תמיכה בקורא מסך, ניגודיות, גופנים מתכווננים.
- **RTL:** מלא, כולל גרפים.
- **ביצועים:** Time to Interactive < 2 שניות. תיעוד מנה < 200ms.
- **מובייל ראשון:** PWA, יעבוד אופליין, ניתן להתקנה כאפליקציה.
- **תמיכה בדפדפנים:** Evergreen (Chrome, Safari, Firefox, Edge - 2 גרסאות אחרונות).

## 9. אזהרות וצמצום סיכונים (Disclaimer Layer)

הממשק חייב לכלול במקומות הבאים:

- **באונבורדינג:** מסך מפורש המסביר שזה כלי מעקב, לא ייעוץ רפואי, וכל שינוי מינון חייב באישור רופא.
- **בתוכנית הפחתה:** לפני יצירת תוכנית - הסכמה מפורשת שהמשתמש מבין שעליו להתייעץ עם רופא.
- **בכל מסך:** קישור עדין בפוטר ל"מתי לפנות לעזרה" עם מספרי טלפון של גורמי תמיכה.
- **תופעות לוואי משמעותיות:** אם המשתמש מדווח על תסמינים מסוימים (דופק מהיר, חרדה קיצונית) - הצעה לפנייה רפואית.

## 11. מדדי הצלחה (KPIs)

- **שימור (Retention):** % משתמשים פעילים אחרי 30 / 60 / 90 יום
- **תיעוד עקבי:** ממוצע ימים שבועי עם תיעוד לפחות מנה אחת
- **השגת יעדים:** % משתמשים שעמדו ביעד שבועי
- **NPS:** האם המשתמשים ממליצים
- **מדד עיקרי (North Star):** ירידה ממוצעת במינון יומי לאורך 90 יום, לחברי תוכנית הפחתה פעילה
